# PHASE Showcase

App presents PHASE functionality by createing audio source in spatial enviroment that can be modified by changing it's postion in 3D space and it's size.

Example is created for iOS but code for PHASE can be succesfully copied to the e.g Mac app. 

Main use case for PHASE framework is game development or enchancing AR experience. Apple uses it for Entities with SpatialAudioComponent provided by RealityKit.
Unfortunetly this framework has only a little avalible examples and documentation.
